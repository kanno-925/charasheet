# キャラシ工房のあゆみ

新しい順。作業が終わるたびに、決まったこと・追加した機能を1〜2行で追記する。
（細かい変更はコミット履歴 `git log` を見る）

## 2026-11-04
- 権限を2段階に：マスター（画面の編集＋権限の変更）と編集者（画面の編集だけ）。マスターは編集パネルの「権限」タブで全員の権限を変えられる。マスターが0人になる変更はできない（supabase/05-app-roles.sql）。
- 画面の編集モードを追加：マスター（`app_admins` に登録した人）だけが部品を選んで色・文字サイズ・余白・角の丸み・透明度・文言・表示/非表示・位置（ドラッグ）を変えられる。編集は下書き→「みんなに公開」で `ui_layout` に保存し、全員の画面に反映。部品はCSSセレクターで覚える（28-ui-editor.js、supabase/04-ui-layout.sql）。
- 探索者をえらぶ画面に「スライド」表示（円形に並び、選んでいないキャラは奥へ回り込む）。
- 魔導書テーマを作り込み：写真の質感の本・録音の効果音、本を画面いっぱい・左右同じ幅に、1頁＝紙1枚の高さで長い項目は頁内スクロール、探索者一覧は本の上・コマ出力は本の下へ。
- 魔導書の模様・書きこみはSVG、写真は紙のしみだけに使う方針。1280px幅でも見開き表示を保つ。
- グループにココフォリアのルームURLを登録できるように。
- アイコン画像の拡大・位置の調整機能。

## 2026-11-03
- 公開。スマホ表示、背景画像時のパネル透過、いあきゃら取り込み。
- オープニング画面 → 探索者をえらぶ画面、という起動の流れ。
- 能力値・技能のグラフ、キャラごとのBGM（ファイル・URL・YouTube）と音量、誕生日。

- テーマのプリセット・並べ替え・背景画像の場所ごとの設定。キャラシ内でダイスを振れる。
- 本のテーマを追加 → 魔導書風のダーク → 古本に万年筆で書きこむデザイン（白黒寄り、書き直し演出）。
