## 2026-11-05
- アクアリウムを作り直し（リアル・海らしく・配置を変える）：はじめの画面（オープニング）はどのテーマでも元のまま（変えないと決定）。角はそろえた厚いガラス（いびつな角はバグっぽく見えたのでやめた）。一覧は真ちゅうの舷窓に入った肖像を横に並べる（パソコンは左に縦）、上の帯は題名と ☰（ボタンは ☰ の引き出しの中）。キャラシは水槽 aquaHtml：大きな舷窓の肖像＋展示の札（名前・職業・年齢・性別・出身）、HP/MP/SAN は泡の立つ液体のガラス管、能力値4列、9つの項目ボタン（3×3）。背景に水底の光の網（assets/aqua/caustics.webp を2枚逆向きに動かす）。小窓のうしろを暗くして下が透けないように。
- アクアリウムの背景を、オーナーからもらった文字なしの絵に差しかえ（assets/aqua/scene.webp、明るさ 0.88 倍。スマホは 62% の位置で遺跡のアーチを見せる）。切りかえのぼやけた水（bokeh.webp）も同じ絵をぼかして作った。はじめの画面の文字のうしろにうすい影。
- アクアリウムの背景を、オーナーの見本の絵（「Loading…」のコマ）から文字を消して使う形に（assets/aqua/scene.webp、少し暗め。スマホは右寄り 88% で大きなくらげと遺跡を見せる）。canvas は光のゆらぎ・粒・泡だけ。切りかえは見本の「編集中…」のように、ぼやけた水（bokeh.webp）にガラスの札・回る光の輪・行き先の名前・Loading…。はじめの画面も見本どおり「Call of Cthulhu / TRPG Character Manager / 貝のしるし / Loading… の棒」。前のテーマの見た目を localStorage `charasheet-kobo.look` に覚え、読み込みを待たずに当てる。
- アクアリウムを見本の画像に寄せた：上の帯は大きな筆記体「Call of Cthulhu」、ホーム・バックアップ・テーマのアイコンつきボタンと歯車（アカウント）、ほかは ☰ の中（aquaMenuSetup）。見出しは「その記録は、きっと、また ——」。一覧は「キャラクター一覧」の見出し＋「＋ 新規作成」（#shelf-new）、大きなガラスのカード（丸い肖像・通過シナリオ数・›）。キャラシのタブはステータス・技能・所持品・メモの4つ＋「詳細を見る」。背景とガラスは深い紺で、ふちだけ光る。
- アクアリウムテーマを追加（look `dark aqua`、js/29-aqua.js・css/19-aqua.css。起動は 30-main.js に番号を変えた）：背景は canvas の水底（光の帯・遺跡・さんご・海藻・魚の群れ・くらげ・泡。動かない所は先に1枚に描く、30コマ/秒）。部品は水滴のようにいびつな角のガラス、明朝と Cinzel・筆記体。キャラシは aquaHtml（貝のしるし・項目のタブ・肖像・HP/MP/SAN の光る棒・能力値のしずく・職業/年齢/性別）。切りかえは aquaWave（水が満ちて泡がのぼり、水が引く）、窓は泡がふくらむ／しぼむ＋波紋、タップは泡、名簿は下から浮かぶ。すりガラスは大きな面だけ（iPhone の重さ対策）。
- テーマを 近未来・和風・魔導書・ドット の4つにしぼった（深淵・古書・ネオン・森を削除）。削除したテーマを使っていた人は、開いたときに近未来へもどす（そのテーマで変えた色も消す。04-import.js の load）。

## 2026-11-04
- 魔導書テーマのとき、本のまわりの画面もそろえた（css/18-book-ui.css）：文字は明朝（Zen Old Mincho・Shippori Mincho B1）と Cinzel、暗いところは革と金の縁、小窓・ココフォリアのコマ・出力は羊皮紙とインク、コピーと決定は赤い封蝋、えらぶ画面は机の写真とろうそくの明かり、「新しい探索者」は封蝋、見出しの軌道は回る金の魔法陣に。
- 魔導書の切りかえを iPhone 向けに直した：3D回転する層では filter（明るさ・光のにじみ）や mix-blend-mode、文字間隔のアニメを使わない（暗さは黒い板の opacity、光は太い線の重ね描き）。重ねる層は translateZ(0) で1枚にまとめ、高さは 100lvh。画面の入れかえは表紙が閉じてから済ませ、そのあと光らせる。タッチ端末は紙2枚。
- 魔導書テーマの画面切りかえを「ふわっと」から本らしい動きに（09-book.js の bookCover。themeSwitchFx に登録）：革の表紙が左の背を軸にバタンと閉じる→彫られた魔法陣が金に光り、行き先（探索者の名前／探索者名簿）が浮かぶ→表紙と紙3枚がめくれて新しい画面。名簿は左からインクで書かれるように出る。本棚で別の探索者に切りかえるときも同じ。前の「閉じた本の写真」（assets/book/closed.webp）は削除。
- 50人・全員立ち絵つきでも保存できるように：IndexedDB にキャラを1人ずつ保存し、変わったキャラだけ書く（前の `state` 1つにまとめた形は自動で移す）。クラウド同期は約3MBずつ分けて送る。
- 保存容量を拡張：キャラシの保存先を localStorage（約5MB）から IndexedDB（数百MB以上）へ。localStorage は入りきるうちだけ予備に使う。IndexedDB を読めないときは、古いデータで上書きしないよう保存を止める。
- フォルダを整理：assets/ をテーマごとのフォルダ（book/・wa/）に分け、名前の頭の「book-」などを外した。build.py はフォルダの中の画像も埋め込み、書いた場所にファイルが無ければ止まる。README のフォルダ構成・SQL一覧・ファイル早見表を最新に。
- ドットテーマを追加（look `dark dot`、css/17-dot.css）：背景は canvas で低解像度に描いた星空・月・流れ星・夜の街・水面・紫陽花（15-theme.js の dotScene）。キャラシは光る枠のボックス（dotHtml、08-hub-panel.js）、ドット文字（DotGothic16・Pixelify Sans）、窓はカクカク開く、切りかえはモザイク（dotMosaic）。
- グループの代表を参加中のメンバーにゆずれるように（編集画面の「代表をゆずる」、サーバー関数 transfer_group。supabase/08-group-transfer.sql が必要）。ゆずった人は参加者として残る。ログインしていない呼び出しは関数の中で止め、anon の実行権も外す（Supabaseは新しい関数をanonにも許可するため）。
- 和風テーマのときは画面の作りごと変える：キャラシは掛け軸（立ち絵）＋縦書きの名前＋「目録」（壱〜玖の一覧）、項目の窓は巻物（上からひらく・巻きあげて閉じる）、切りかえは襖、筆文字（Yuji Syuku）と明朝（Zen Old Mincho）。waHtml は 08-hub-panel.js。
- 和風テーマを作り直し（look `wa`、css/16-wa.css）：和紙・墨・金、参考画像から切り出した景色（assets/wa-scene.webp）、金の霞と青海波はSVG、舞い散る桜（canvas）と枝のゆれ。探索者一覧は墨色の帯に金の家紋。
- いあきゃらの「テキスト出力（.txt）」を丸ごと取り込めるように（6版・7版）：技能の内訳（職業P・興味P・成長・その他）、能力値の増加分、武器、所持品、財産、経歴、魔導書・遭遇した存在、通過シナリオ、メモ、追加プロフィール。「ココフォリア駒出力」には合計値しか入っていないため。
- アカウントのアイコン画像（profiles.avatar、160pxの正方形を data URL で保存。supabase/07-avatars.sql）。フレンド一覧・申請・探索者をえらぶのフレンド・グループに表示。
- スマホ・iPad対応の修正：入力欄は16px以上（iPhoneの拡大防止）、タッチ画面では魔導書の3Dの傾きを切る、タップ後にホバーの動きを残さない、小さい画面で見出しが切れない。
- 探索者は1人最大50人まで（新規・複製・読み込みで確認）。
- 編集モードの修正：フォントは中の部品にもまとめて効かせる（アプリが部品ごとにフォントを決めているため、外側だけでは変わらなかった）。スマホでは下から出るパネルをつまみで小・中・大に切りかえ、選んだ部品が隠れないよう自動でスクロール。「内側へ」ボタン、指で押しやすい大きさ、入力時に画面が拡大されないように。
- 編集モードを強化：フォント（Googleフォント）・太さ・文字間隔・行の高さ・文字の影、背景画像／画像の差しかえ（Storage `ui-assets`）、横幅・高さ（右下の四角をドラッグでも）・切り抜く形・ふち・影・回転・拡大。
- 公開できるのはマスターだけに。編集者は「仮保存」（`ui_drafts`）まで。マスターは「仮保存」タブで読み込んで確認→公開・削除できる（supabase/06-ui-drafts.sql）。
- 権限を2段階に：マスター（画面の編集＋権限の変更）と編集者（画面の編集だけ）。マスターは編集パネルの「権限」タブで全員の権限を変えられる。マスターが0人になる変更はできない（supabase/05-app-roles.sql）。
- 画面の編集モードを追加：マスター（`app_admins` に登録した人）だけが部品を選んで色・文字サイズ・余白・角の丸み・透明度・文言・表示/非表示・位置（ドラッグ）を変えられる。編集は下書き→「みんなに公開」で `ui_layout` に保存し、全員の画面に反映。部品はCSSセレクターで覚える（28-ui-editor.js、supabase/04-ui-layout.sql）。
- 探索者をえらぶ画面に「スライド」表示（円形に並び、選んでいないキャラは奥へ回り込む）。
- 魔導書テーマを作り込み：写真の質感の本・録音の効果音、本を画面いっぱい・左右同じ幅に、1頁＝紙1枚の高さで長い項目は頁内スクロール、探索者一覧は本の上・コマ出力は本の下へ。
- 魔導書の模様・書きこみはSVG、写真は紙のしみだけに使う方針。1280px幅でも見開き表示を保つ。
- グループにココフォリアのルームURLを登録できるように。
- アイコン画像の拡大・位置の調整機能。
